# Questy 2.0 — VK Mini Apps

Проект мини-приложения с ежедневными заданиями, экономикой Q, календарём и косметикой. **Ветка `feature/questy-2-stage1-architecture` — первый технический этап Questy 2.0, не публичный релиз.**

## Что готово на этапе 1

- Пять пунктов навигации: **Главная, Приключения, Календарь, Лавка, Профиль**.
- На главном экране сохранены задание дня, плёнка, две сложности, серии и замены заданий. Добыча Q открывается отдельной кнопкой.
- Добыча Q с улучшениями, балансом, ежедневным подарком и рекламным ускорителем сохранена.
- Сохранились лавка тем/рамок, профиль, достижения, цели и календарь.
- Тематический селектор из ежедневных заданий убран в соответствии с принятыми требованиями; старые настройки не стираются.
- Стили разделены на `css/`, игровая логика — на `js/`, инициализация вынесена отдельно.
- Существующие ключи VK Storage и `g_*` оставлены без переименования; добавлена **недеструктивная** миграция старых локальных записей.
- Вкладка «Приключения» пока содержит **заглушку**. Каталог, истории и марафоны будут реализованы на следующих этапах.

## Как запустить

Приложение остаётся статическим: HTML + CSS + обычный JavaScript, **без npm и сборки**. Для корректной загрузки внешних файлов лучше открывать через локальный HTTP-сервер или GitHub Pages, не через `file://`.

На компьютере с Python: `python -m http.server 8000`, затем открыть `http://localhost:8000`.

На GitHub Pages используется содержимое выбранной ветки; не заменяйте действующую публичную версию до ручных проверок.

## Структура

```text
index.html             — разметка экранов
css/base.css           — исходные базовые стили и экран задания
css/features.css       — добыча, календарь, магазин, профиль
css/navigation.css     — навигация, модальные окна, новые элементы
js/core.js             — константы, время, VK Bridge, уведомления
js/content.js          — ежедневные задания, палитры, рамки
js/state.js            — глобальное состояние, очередь сохранений, парсеры
js/migrations.js       — переход со старых локальных ключей
js/mining.js           — экономика добычи Q
js/ui.js               — темы, обновление интерфейса, маршрутизация и загрузка
js/daily.js            — задания, плёнка, рероллы, реклама
js/goals-achievements.js — цели и достижения (сохраняем существующий функционал)
js/calendar-shop.js    — календарь, магазин и шаринг
js/bootstrap.js        — запуск, смена дня, восстановление WebView
scripts/check-stage1.mjs — автоматическая статическая проверка
.github/workflows/stage1-check.yml — проверка ветки и PR
QA.md                  — ручные сценарии испытаний
```

**Архитектурная оговорка:** JS пока загружается **последовательно обычными script-тегами**, а не ES-модулями. Это осознанный совместимый первый шаг: исходный код сильно связан общими переменными. В следующих этапах можно постепенно вводить настоящие модули и явные зависимости, не ломая старые сохранения.

## Проверка

```bash
node scripts/check-stage1.mjs
```

Проверка использует только встроенные модули Node.js, ничего устанавливать не нужно. Она проверяет синтаксис, порядок файлов, уникальность HTML ID, пять вкладок и отсутствие перезаписи старых сохранений при миграции.

**Не проверяется автоматически:** запуск в реальном VK WebView, корректность рекламных callback, покупки голосами VK, мобильные жесты и долговременное облачное восстановление. Это ручные обязательные проверки перед релизом.

## Этап 2 — библиотека и истории

Этап 2 разрабатывается в ветке `feature/questy-2-stage2-adventures`, отдельно от этапа 1 и опубликованной версии.

### Контент

- 50 бесплатных быстрых испытаний: 20 для одиночного прохождения, 15 для пары и 15 для компании на одном устройстве.
- 10 интерактивных историй: **7 бесплатных и 3 премиальных**.
- У каждой истории есть выборы, 2 различных окончания и 8 сюжетных шагов по пути к финалу.
- Сюжеты содержатся в `js/adventure-content.js`. Все узлы имеют стабильные идентификаторы для сохранения прогресса.

### Функции

- Каталог с поиском и фильтрами по типу, режиму участников, сложности, длительности, доступу и статусу.
- Избранное, пройденные и незавершённые истории.
- Выполнение этапа по кнопке, выбор пути, возможность отложить и переиграть историю.
- Пропуск обычного/сложного/особого этапа за **200/350/500 Q** либо за подтверждённую наградную рекламу.
- История пройденных сцен и решений, сохранение открытых концовок при повторном прохождении.

### Доступность премиума

**В текущем этапе премиальные истории недоступны для покупки и прохождения.** Описания доступны в библиотеке, но доступ требует подтверждения оплаты — эту часть подключим на этапе 4. В приложении нет ложных кнопок оплаты или бесплатных обходов.

### Сохранения

Новые ключи: `questy_adventure_favorites_v1`, `questy_quick_results_v1`, `questy_story_v1_<id>`. При работе в локальном браузере сохраняются как `g_<key>`, в VK Storage — без префикса. Данные не перезаписывают старые ключи Q, серий, добычи и профиля.

Синхронизация нескольких устройств пока использует обновление по времени последнего изменения. Это не замена серверной защиты от конфликтов и гонок.

### Проверка этапа 2

```bash
node scripts/check-stage2.mjs
```

Тест запускает также проверки первого этапа. Требуется Node.js, но **не npm**. В GitHub Actions есть `.github/workflows/stage2-check.yml`.

Ручные проверки в реальном VK WebView обязательны перед объединением/релизом. Весь каталог марафонов и новый контент ежедневных заданий будут добавлены позже.

## Этап 3 — строго три приключения и ежедневные марафоны

**Раздел «Приключения» теперь показывает только три предложения текущей недели.** Убраны поиск и полный каталог будущих историй, чтобы игрок не видел, что ему выпадет дальше. Смена списка — за подтверждённую наградную рекламу. Правила недельного бесплатного выбора и покупки двух историй за Q сохранены.

- Ранее открытые и приобретённые истории находятся в **«Профиль» → «Мои приключения»**, а не в недельной тройке.
- Все 50 быстрых испытаний по-прежнему доступны, но их полный список скрыт; в **«Календаре»** есть кнопка «Случайное испытание».
- Пять марафонов находятся в **«Календаре»**, отдельно от трёх приключений: 3 бесплатных (3, 7 и 7 дней), 2 премиальных (30 и 30 дней). Премиальные пока заблокированы до реальных покупок голосами VK.
- Марафоны открывают **один этап за календарный день**. Пропуск даты завершает попытку провалом; никакие Q/реклама не восстанавливают пропущенный день. Новую бесплатную попытку можно начать с первого дня.
- Прошлые успешные и проваленные попытки сохраняются, а будущее содержание марафона не раскрывается заранее.
- Добавлены достижения за первое сюжетное приключение и первый завершённый марафон.
- Новое сохранение `questy_marathons_v1`, старые ключи и баланс Q не переименованы.

### Тесты этапа 3
```bash
node scripts/check-stage3.mjs
```
Проверка включает тесты этапов 1, 2, недельной выдачи и календарных марафонов. Нужен только Node.js, npm не требуется.

**Ограничение безопасности:** календарь и Q по-прежнему опираются на клиентские/VK Storage данные. Защита от смены часов и атомарные межустройственные транзакции требуют серверной проверки до полноценного коммерческого релиза.
