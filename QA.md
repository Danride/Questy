# Проверка Questy перед отправкой в каталог

## Запуск и дизайн
- [ ] На Android, iOS и десктопе видны пять исходных вкладок; горизонтального скролла нет.
- [ ] Начальный экран показывает подсказку один раз, при следующем входе не мешает.
- [ ] Все исходные цвета, текстуры и анимация стирания плёнки сохранены.
- [ ] На узком экране 320 px доступны ввод цели, выбор шагов и кнопки.
- [ ] Клавиатура мобильного устройства не перекрывает ввод новой цели.

## Задания и цели
- [ ] Обычная и сложная категории открываются по исходным правилам.
- [ ] Тематика влияет на новые задания и не позволяет бесплатно менять уже открытое.
- [ ] Все пять тематик дают разные корректные задания; повторов при рероллах по возможности нет.
- [ ] «Сделал» / «Не сделаю» остаются взаимоисключающими и сохраняются после перезапуска.
- [ ] Отметка «Сделал» не добавляет Q.
- [ ] Цель можно создать, увеличить прогресс, завершить и удалить; все состояния сохраняются после перезапуска.
- [ ] 12 активных целей — предел; ввод длиннее 80 символов не сохраняется.
- [ ] Достижения обновляются после выполнения задания и закрытия цели.
- [ ] Профиль и история не теряют ранее созданные данные.

## Даты и сохранения
- [ ] После смены календарного дня без закрытия WebView задания и лимит попыток обновляются.
- [ ] Купленные дополнительные попытки не переносятся на следующие дни.
- [ ] Перезапуск и восстановление WebView не создаёт дубли выполненных заданий.
- [ ] Синхронизация между двумя устройствами: задания, баланс и цели не откатываются.
- [ ] Часы телефона назад/вперёд не создают отрицательных ресурсов в добыче.
- [ ] При нестабильном интернете и сбое VK Bridge интерфейс не зависает и локальные данные не пропадают.

## Реклама и экономика
- [ ] Отменённая / закрытая / не загрузившаяся реклама не даёт награду.
- [ ] Нет кнопки «Пропустить и получить».
- [ ] Успешная реклама даёт только соответствующую награду.
- [ ] Покупки тем, рамок и попыток не списывают Q повторно.
- [ ] Награда за первый репост выдаётся только после подтверждённой успешной операции.

## Каталог и приватность
- [ ] Проверены официальные актуальные правила VK Mini Apps.
- [ ] Добавлены достоверные описания, изображения и инструкции для модераторов.
- [ ] Уточнено и реализовано удаление персональных данных (в текущей ветке не готово).
- [ ] Проверены согласие с правилами и политика конфиденциальности, если требуются для выбранного сценария.
- [ ] Отправлено на проверку только после тестирования внутри VK; успешный анализ синтаксиса не равен проверке работы.

- JavaScript внутри `index.html` успешно разобран парсером V8 (`new Function`, без исполнения).
- Не найдены повторяющиеся HTML id.
- Нет повторяющихся объявлений обычных функций.
- Подтверждено статически наличие 50 новых заданий и отсутствие обработчика «Пропустить и получить».
