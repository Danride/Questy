# Questy 2.0 — QA, первый этап

## Автоматически проверяемое

Запустить `node scripts/check-stage1.mjs` или дождаться GitHub Actions.

- [ ] Каждый JS-файл и их конкатенация разбираются V8 без синтаксических ошибок.
- [ ] HTML не содержит дублированных ID и имеет пять согласованных вкладок.
- [ ] `index.html` подключает стили и скрипты в правильном порядке.
- [ ] Кнопки входа в добычу Q и возврата на главную существуют.
- [ ] При миграции существующий `g_balance` не заменяется более старым `balance`.
- [ ] Старые `streak`, `owned_themes`, `history`, `mining`, дневное состояние копируются только при отсутствии `g_...`.
- [ ] Повторная миграция не меняет сохранения.

## Обязательно проверить вручную в браузере и VK WebView

- [ ] Приложение запускается без ошибок в консоли, появляется основная страница.
- [ ] Вкладки «Главная», «Приключения», «Календарь», «Лавка», «Профиль» переключаются.
- [ ] На главной работает стирание плёнки касанием и мышью, две сложности, серия, повторные задания.
- [ ] Кнопка «Добыча Q» открывает добычу, «← Главная» возвращает назад.
- [ ] Пока каталог не готов, «Приключения» показывают только информационную заглушку.
- [ ] В добыче работают начисление, сбор, апгрейды, хранилище и ускоритель.
- [ ] Календарь, цели, достижения, лавка тем и рамок не теряют данные.
- [ ] Проверен экран шириной 320–360 px: кнопки не налезают и не обрезаются.
- [ ] Мобильная клавиатура не перекрывает создание целей.
- [ ] Отключённый/недоступный VK Bridge не приводит к зависанию старта.

## Проверка сохранений

- [ ] Баланс Q, серия, купленные Q-темы и рамки сохраняются после перезагрузки.
- [ ] При переходе с старой версии с `g_*` прогресс не обнуляется.
- [ ] При наличии только прежних локальных ключей данные копируются в `g_*`.
- [ ] Между двумя устройствами VK Storage не вызывает случайный откат более нового состояния.
- [ ] Смена суток и восстановление из фонового режима корректно обновляют задание.
- [ ] Нельзя получить Q только нажатием «Сделал».
- [ ] Отменённая или неуспешная реклама не даёт награду.

## Блокеры релиза Questy 2.0

- [ ] Полностью реализованы истории, марафоны, библиотека и оформление.
- [ ] Наполнен и отредактирован весь согласованный каталог.
- [ ] Проверена безопасность покупок и возврат доступа к платному контенту.
- [ ] Реализованы необходимые документы и удаление пользовательских данных.
- [ ] Пройдены реальные проверки Android, iOS и десктопного VK.
- [ ] Проверено соответствие актуальным требованиям VK Mini Apps.

**Статус:** автоматическая проверка — ограниченная статикой; реальные сценарии пока не объявлены пройденными.

## Этап 2 — библиотека приключений

- [ ] 50 быстрых испытаний отображаются в каталоге и доступны бесплатно.
- [ ] 10 сюжетных историй отображаются: 7 бесплатных, 3 премиальных.
- [ ] Поиск по названию работает без потери фокуса поля.
- [ ] Фильтры «Тип», «Игроки», «Сложность», «Время», «Доступ», «Статус» работают в комбинации.
- [ ] Избранное добавляется/снимается и сохраняется после перезапуска.
- [ ] Прогресс истории сохраняется после «Отложить», закрытия VK WebView и возврата.
- [ ] На выбор пути не тратятся Q; «Выполнил» тоже не тратит и не добавляет Q.
- [ ] Пропуск обычного этапа списывает 200 Q, сложного — 350 Q, особого — 500 Q.
- [ ] При недостатке Q пропуск невозможен и прогресс не изменяется.
- [ ] При закрытии/ошибке рекламы прогресс не изменяется, а после подтверждённого просмотра этап пропускается.
- [ ] Быстрые повторные нажатия по «Пропустить» не вызывают двойного списания.
- [ ] История решений отражает выполненные и пропущенные узлы.
- [ ] Повторное прохождение сохраняет ранее открытые концовки.
- [ ] Все 10 сюжетных графов достигают двух финалов без обрыва сюжета.
- [ ] Премиальные истории не продаются и не открываются без настоящей проверки покупки.
- [ ] Существующие Q, добыча, ежедневные задания, темы и рамки не теряются.
- [ ] На 320–360 px кнопки и длинные тексты не выходят за границы экрана.
- [ ] Переход из каталога в добычу/главную не сбрасывает текущую историю.
- [ ] Перезапуск на втором устройстве не приводит к неожиданному откату нового прогресса.
- [ ] На Android, iOS и десктопе VK WebView все действия проходят без ошибок.

**Автоматическая проверка:** `node scripts/check-stage2.mjs`; любые браузерные/платёжные проверки должны выполняться отдельно.
