# Каталог Questy 2.0 — этап 2

## Быстрые испытания

В `js/adventure-content.js` находятся **50 разных испытаний**: 20 индивидуальных, 15 для пар, 15 для компании. Они бесплатные, могут проходиться повторно и не начисляют Q при подтверждении.

## Истории

| ID | Название | Режим | Доступ |
|---|---|---|---|
| letters | Станция забытых писем | Один | Бесплатно |
| flat-zero | Квартира номер ноль | Один | Бесплатно |
| last-light | Последний фонарь | Пара | Бесплатно |
| pizza | Операция «Пицца» | Компания | Бесплатно |
| house-of-clocks | Дом без часов | Пара | Бесплатно |
| museum | Тайна школьного музея | Компания | Бесплатно |
| radio | Ночная радиоволна | Один | Бесплатно |
| unmapped-city | Город без названия | Один | Премиум |
| promise | Договор на двоих | Пара | Премиум |
| king-trial | Суд над королём | Компания | Премиум |

У каждой истории **12 узлов графа** (задачи, выборы и 2 финала). Путь до концовки содержит 8 этапов. Развилки меняют действия, к последнему выбору возможны разные пути; финал определяется последним решением игрока.

## Механика

- Обычный этап — **200 Q**, сложный — **350 Q**, особый — **500 Q** за пропуск.
- Альтернатива — один подтверждённый просмотр наградной рекламы.
- Пропущенная сцена фиксируется как `skipped`, а не `done`.
- Выборы между сюжетными ветвями бесплатны.
- «Выполнил» и выполнение быстрых испытаний не создают Q.
- При перезапуске истории сохраняется количество прохождений и список ранее открытых концовок.

## Предупреждения

- Премиальные истории закрыты до подключения серверно подтверждённых покупок голосами VK.
- Списание Q пока работает через локальное/облачное клиентское состояние исходного приложения. Для защиты монетизации на следующем этапе потребуются серверные транзакции с проверкой.
- При одновременной игре на двух устройствах возможен конфликт сохранений. Текущая синхронизация сравнивает `updatedAt` (время телефона), но это не строгая гарантия.
- Тесты проверяют модель и игровую логику, а не реальные нажатия и вёрстку в VK WebView.
